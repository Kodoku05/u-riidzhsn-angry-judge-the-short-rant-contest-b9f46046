A short funny rant about an everyday annoyance, written by a program for the Angry Judge contest: a courier leaves a missed-delivery card while the recipient is watching. The program writes the same text to `entry.txt` in `MAKEFUN_OUTPUT_DIR`, or `/output` by default, using only Node's standard library.

## Run it

```sh
node main.ts
```
